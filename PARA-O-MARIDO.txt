PARA O MARIDO — baixar e atualizar o Editor de Vídeo
====================================================

1) Na PRIMEIRA VEZ no notebook
-----------------------------
Instale (se ainda não tiver):
- Git: https://git-scm.com/download/win
- Python: https://www.python.org/downloads/  (marque "Add Python to PATH")
- FFmpeg: abra o PowerShell e rode:  winget install Gyan.FFmpeg

Depois abra o PowerShell ou o Prompt de Comando e rode
(cole o comando que está no final deste arquivo, com o link certo):

  git clone URL_DO_GITHUB
  cd EditorDeVideo
  Abrir Editor.bat

Ou no site do GitHub: botão verde "Code" → "Download ZIP" → extrair a pasta.
(Se baixar por ZIP, o Atualizar.bat só funciona depois de usar git clone.)


2) Quando a esposa ATUALIZAR o programa
---------------------------------------
Ela sobe a novidade no GitHub.
No seu notebook: abra a pasta do EditorDeVideo e dê dois cliques em:

  Atualizar.bat

Pronto — ele baixa a versão nova sozinho.
Depois abra de novo com: Abrir Editor.bat
