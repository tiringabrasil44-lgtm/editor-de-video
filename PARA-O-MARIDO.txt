PARA O MARIDO — baixar e atualizar o Editor de Vídeo
====================================================

Link do GitHub:
https://github.com/tiringabrasil44-lgtm/editor-de-video


1) Na PRIMEIRA VEZ no notebook
-----------------------------
Instale SÓ o Python (uma vez):
https://www.python.org/downloads/
→ marque a caixinha "Add python.exe to PATH"
→ Install Now

(Opcional, só se for usar Atualizar.bat)
Git: https://git-scm.com/download/win

Depois no PowerShell:

  git clone https://github.com/tiringabrasil44-lgtm/editor-de-video.git
  cd editor-de-video

Abra: Abrir Editor.bat
Na primeira abertura ele BAIXA O FFMPEG SOZINHO.
Nao precisa Path, nem extrair zip na mao.


2) Quando a esposa ATUALIZAR
----------------------------
Dois cliques em: Atualizar.bat
Ele puxa a novidade do GitHub e instala o que faltar.
Depois abra: Abrir Editor.bat


Nao precisa instalar FFmpeg manualmente.
